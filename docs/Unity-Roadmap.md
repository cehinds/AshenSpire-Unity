# AshenSpire Unity roadmap

Target: the original AshenSpire, faithfully rebuilt in Unity with its painterly
aesthetic, mobile-first controls, smoother animation and clearer, consistent UI.
The previous simplified campaign is a compatibility checkpoint. It does not
replace the original game's feature scope.

## Verified foundation in 0.9.0

- [x] Pin the original dev reference and retain content provenance.
- [x] Import the original content bundle: cards, relics, statuses, enemies, events,
  classes, equipment, upgrades and unlock definitions.
- [x] Native C# seeded random streams, counters and resume state.
- [x] Original structured formulas, tag joins and derived stat calculation.
- [x] Original class presets, allocation budgets and base resource previews.
- [x] Original health/mana flask allocation ledger.
- [x] Seeded three-act map graphs, node types and route exploration.
- [x] Status stacking, decay, meters, procs and damage calculation components.
- [x] Explicit combat effect queue with isolated event snapshots.
- [x] Owner catalog search, CSV export/import, backups and stale-file checks.
- [x] Pure domain assembly; .NET naming and folder conventions; script headers.
- [x] Original-engine differential fixtures and compiled Web interaction checks.
- [x] Rebuild Web, Windows and Android players; capture fresh screenshots.

These checks establish foundation behavior. They do not establish full-run parity.

## Required original gameplay integration

- [ ] Complete original framework/property validation and runtime adoption.
- [ ] Start a real run from the original class, attributes and selected loadout.
- [ ] Resource costs, card instance zones, draw/discard/exhaust/retain lifecycle.
- [ ] Multi-enemy targeting, turns, AI, deaths, triggers, dodge and poise.
- [ ] Every original card/relic/status effect executes through native commands.
- [ ] Equipment ownership, sets, card recomposition and stat projections.
- [ ] Smithing, upgrades, extraction, installation and related services.
- [ ] Encounter assignment, unknown rooms, rewards, shops, events and shrines.
- [ ] Complete original acts and bosses with deterministic command-trace evidence.
- [ ] Profiles, unlocks, run history, custom runs and versioned original-run saves.
- [ ] Native co-op connection, host authority, synchronization and multiplayer QA.

## Polish and release readiness

- [ ] Compare original and Unity screens side by side; preserve visual identity.
- [ ] Finish sprite animation, combat feedback, transitions, sound and music.
- [ ] Complete consistent touch UI for all original-game systems.
- [ ] Validate real Android hardware, native desktop interaction and iOS builds.
- [ ] Measure loading, memory and frame performance on target phones.
- [ ] Deliver a complete original-game playthrough and regression evidence.
- [ ] Owner selects test/release/main candidates after reviewing the dev build.
